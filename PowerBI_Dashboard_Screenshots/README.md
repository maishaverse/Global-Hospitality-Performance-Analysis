# Dashboard Screenshots

Power BI dashboard screenshots showing the three audience-specific pages:
- Executive Summary — portfolio-level KPI scorecard
- Regional Insights — subregion and channel breakdown
- Property Overview — property-level performance and guest segments

> **Note:** The Power BI file (.pbix) is not included in this repository 
> as it contains embedded proprietary data. Dashboard screenshots are 
> available in the `PowerBI_Dashboard_Screenshots/` folder.
> Data used in this project was provided as part of a case study exercise. All figures shown are aggregated KPIs — no individual guest or transaction data is included.
